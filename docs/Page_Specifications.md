# Page Specifications - SkillSwap (9 Pages)

1. **Login Page (`/login`)**: Public authentication card, email/password inputs, quick demo user selector.
2. **Register Page (`/register`)**: Public signup card with full name, email, password.
3. **Dashboard Page (`/dashboard`)**: Private overview with stat cards (Points, Active Sessions, Skills Offered/Wanted), top peer matches, recent sessions.
4. **My Profile / Peer Profile (`/profile`, `/profile/:id`)**: Editable tag input chips for skills offered/wanted, bio, education, or view peer with "Request Session" trigger.
5. **Discover Page (`/discover`)**: Search by skill, filter cards sorted by `mutualScore`, visual score badges, skill overlap breakdown.
6. **Session Tracker Page (`/sessions`)**: Tabbed board (All, Requested, Confirmed, Completed), schedule form, state transition buttons (Confirm, Complete, Reject).
7. **Resources Page (`/resources`)**: Shared resource feed, tag filter chips, external links, "Share Resource" modal.
8. **Portfolio Page (`/portfolio`, `/portfolio/:id`)**: Auto-compiled view of total points, skills learned/taught, completed session records, shared resources.
9. **404 Not Found Page (`*`)**: Error layout with dashboard navigation button.
